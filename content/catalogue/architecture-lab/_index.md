**Architecture Lab** is a Mightora browser application for creating architecture diagrams. It is listed under Architecture & Planning alongside Technology Radar and Roadmaps.

[Open Architecture Lab](https://architecture-lab.mightora.io/) · [Explore architecture and planning tools](/#architecture) · [Browse Mightora source projects](https://github.com/mightora)

## When should I use Architecture Lab?

Use an architecture diagram when a written description is not enough to explain components and their relationships. For example, sketch the main application components and integrations before discussing a proposed solution with colleagues.

Diagrams can support an architecture review, but they are not a substitute for validated system requirements, threat modelling or tested deployment configurations.

## A practical modelling exercise

1. Identify the users, systems and key integrations in your solution.
2. Open [Architecture Lab](https://architecture-lab.mightora.io/) and choose an appropriate drawing approach.
3. Represent the components and the connections that need explanation.
4. Review the diagram with stakeholders and maintain the supporting decisions and assumptions.

## Related tools

Use [Technology Radar](https://radar.mightora.io/) to visualise technology decisions and [Roadmaps](https://roadmaps.mightora.io/) to plan delivery workstreams and dependencies.

## Scope and limitations

The verified catalogue description is “Create architecture diagrams.” Import and export formats, offline capability, account requirements, data handling and support for deeper modelling are not verified by this description. Check the current application and source code before relying on those capabilities.
