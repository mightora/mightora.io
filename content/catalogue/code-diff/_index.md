# Code Diff: compare code and web files

**Code Diff** is a Mightora browser tool for comparing code and web files. It can help developers examine differences while reviewing an implementation, investigating a regression or preparing a change.

[Open Code Diff](https://code-diff.mightora.io/) · [Browse the other debugging tools](/#diagnostics) · [Browse Mightora source projects](https://github.com/mightora)

## When should I use Code Diff?

Use a comparison tool when you have two versions of a source file or code fragment and need to understand what changed. For example, compare a working snippet against a revised snippet before updating a Power Platform web resource.

A visual comparison can assist review, but it does not establish correctness, security or functional equivalence. Always run the relevant tests on the code you intend to deploy.

## How to get started

1. Open the [Code Diff application](https://code-diff.mightora.io/).
2. Choose the comparison mode the currently deployed application supports.
3. Provide the two inputs and review the differences.
4. Verify important changes in your normal development workflow.
